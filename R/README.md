# R scripts

Scripts will be added as the project progresses. Suggested sequence:

1. `01_inspect_data.R` — import data and inspect its structure.
2. `02_clean_data.R` — validate coding and document cleaning decisions.
3. `03_descriptive_analysis.R` — summarise adoption indicators.
4. `04_visualise_adoption.R` — create labelled charts.
5. `05_additional_analysis.R` — run a justified statistical test or model, if appropriate.

Use relative paths and explain important analytical decisions in comments. Do not add scripts that assume variable names until the dataset and codebook have been reviewed.
