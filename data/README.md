# Data

This directory documents the data used by the project.

- `raw/`: locally stored source data. Do not commit raw data unless its licence and access terms explicitly permit redistribution.
- `processed/`: derived, analysis-ready data where appropriate. Do not commit confidential or restricted records.

Before analysis, document the dataset citation, source URL, access date, licence or terms of use, study population, sampling design, relevant variables, and any survey weights. Keep data access and cleaning decisions reproducible.
