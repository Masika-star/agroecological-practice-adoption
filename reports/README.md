# Reports

This directory contains written records of the project's data checks, analytical decisions, findings, and limitations.

## Available report

- [`initial-data-quality-audit.md`](initial-data-quality-audit.md) — records the initial dataset dimensions, removal of fully empty columns from the working copy, duplicate checks, farm-type distribution, and variable-level missingness as of 31 October 2026. It also lists outstanding validation tasks.

## Planned report

A Quarto report (for example, `report.qmd`) may be added after the dataset source, research question, and variable definitions have been confirmed. Reports should be reproducible from the scripts and should distinguish exploratory findings from substantive conclusions.
